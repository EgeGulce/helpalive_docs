**Guides** are interactive in-product walkthroughs — multi-step flows that lead a user through a task, with highlights and tooltips on real elements in your product. They're managed from **Studio → Guides** in your dashboard.

<Note>
  **Status today.** The guide runtime is shipped and battle-tested. The Studio guide editor is in active development. Until that ships, custom guides for early-access customers are authored directly by HelpAlive on request.
</Note>

## What guides do

<CardGroup cols={2}>
  <Card title="Highlight what matters" icon="target">
    A spotlight overlay points to the exact element on the page — a button, a tab, a form field — and dims everything else.
  </Card>
  <Card title="Walk through tasks" icon="list-checks">
    Steps advance as the user clicks through, so they learn by doing — not by reading.
  </Card>
  <Card title="Stay accurate as you ship" icon="shield">
    Guides match elements by their meaning (role, label, position), so they keep working when your UI changes.
  </Card>
  <Card title="Run in any product" icon="globe">
    Guides work in any web app, no matter what framework or component library it's built with.
  </Card>
</CardGroup>

## How guides will be used

1. **You build a guide** in **Studio → Guides** — record it by clicking through your product, or define steps in the editor.
2. **Stage it as a draft** — guides go through the same draft / publish workflow as the Agent.
3. **Target who sees it** — segment by workspace, role, plan, or page. Per-workspace exclusions are first-class.
4. **It runs when triggered** — programmatically via the SDK, or (coming) when the Agent identifies a goal that matches a published guide.
5. **You measure the impact** — every step emits an event. Completion rates, drop-off steps, and friction inside guides flow back into your analytics.

## What works today

The guide **runtime** — the part that runs guides in your users' browsers — is fully shipped:

- Reliable element matching across page navigations and UI changes.
- Spotlight overlay and tooltips that feel native to your product.
- Lifecycle events you can subscribe to (started, advanced, deviated, abandoned, completed).
- Workspace-level rollout exclusions.

Trigger a guide programmatically with the SDK any time:

```javascript
HelpAlive.startGuide(guide, options);
```

See the [SDK API reference](/sdk/api-reference) for the full method list.

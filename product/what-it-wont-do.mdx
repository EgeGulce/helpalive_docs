HelpAlive's agent follows the same safety rules in every app: steps it hands back to the user, things it asks before doing, and how it answers. This page lists them. It is for admins and security reviewers who want to know them before turning the agent on.

## Safety at a glance

- Even with **Does the steps**, the agent hands back uploads, codes sent to the user, passwords it was not given, and anything outside your page.
- It asks before writing to a record the user didn't name, and once before deleting many records by a rule.
- It answers from your published sources on **Train**. Your users never get answers from drafts.
- It never hides that it's an AI.
- These rules hold in every app, with nothing to set up.

## Steps the agent always hands back

During an assist, even with **Does the steps**, the agent hands these steps to the user and says so:

| Step | Why |
|---|---|
| Uploading a file | Only the user has the file. |
| A code sent to their phone or email | Only the user receives it. |
| A password or other sign-in detail it was not given | Only the user should type it. |
| Downloads, file pickers and the browser's or computer's own dialogs | It can't operate or check them, because they sit outside your page. |
| Anything in another app or another site | It works only inside your app, in the tab the user has open. |

When it hands a step back, the control is highlighted when it can be, and the bar says **Your turn**, which means that the step is the user's. The user presses **Done** when finished, or **Skip**.

## Things the agent always asks first

- **Content only the user can give.** A name, a message's wording, a choice that is theirs to make. It asks at the moment it needs the answer, one thing at a time.
- **A record the user didn't name.** If a change would land on a record the user never named, it asks before writing.
- **Deleting many records by a rule.** This refers to a request like "delete all drafts except the last one". It finds the records, names them, and asks once before the first deletion. One answer covers the whole set.

<Warning>
With **Does the steps**, the agent presses Save, Submit and Delete when the task calls for it. Deleting by a rule is the one case where it always confirms first. If you want users to make every click themselves, set **Shows how** on **Controls**.
</Warning>

## How the agent answers

- **It won't stretch a feature to fit.** When your app can't do something, it says so plainly, then helps with the parts it can.
- **It sticks to your sources.** It answers from your published sources on **Train**. Where your docs are silent, it can use general knowledge of your product, and your docs win when the two disagree. It doesn't invent links, ids or quoted text. Like any AI, it can still make mistakes.
- **It won't use drafts.** Your users get answers from published sources only. Drafts show only on **Test**.
- **It won't hide that it's an AI.** It says so when asked, and the chat's footer says "HelpAlive is AI and can make mistakes."

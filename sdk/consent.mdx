HelpAlive supports two consent modes and a runtime toggle so you can integrate with whatever consent banner or compliance flow you already run.

## Modes

| Mode | Behavior |
|------|----------|
| **Auto** (default) | HelpAlive starts capturing as soon as the script loads. Use this where your local rules don't require prior consent. |
| **Consent required** | HelpAlive loads but stays silent until you call `setConsent({ analytics: true })`. |

Choose the mode on the tag itself: add `data-consent="required"` to the script tag for **Consent required**, and leave it out for **Auto**.

```html
<script src="https://cdn.helpalive.com/sdk/helpalive.js" data-api-key="YOUR_PROJECT_KEY" data-consent="required" async></script>
```

## Runtime toggle

Even in auto mode, you can change consent at any time — useful when a user updates their preferences in your privacy center.

```javascript
// User accepts
HelpAlive.setConsent({ analytics: true });

// User rejects
HelpAlive.setConsent({ analytics: false });
```

| Field | Effect when `false` |
|-------|---------------------|
| `analytics` | HelpAlive stops recording activity for this user. Anything queued but unsent is dropped. |

`analytics` is the only field. There is no separate switch for the agent: to keep it away from some people, leave them out of the rollout on **Agent → Configuration**.

## Wiring it to your cookie banner

```javascript
// 1. Add data-consent="required" to the HelpAlive tag so the script
//    loads but stays silent until you call setConsent().

// 2. Show your cookie banner and pass the choices through.
showConsentBanner({
  onAccept: (choices) => {
    HelpAlive.setConsent({ analytics: choices.analytics === true });
  },
  onReject: () => {
    HelpAlive.setConsent({ analytics: false });
  }
});
```

## GDPR-style explicit opt-in

For EU traffic where prior consent is required:

1. Add `data-consent="required"` to the HelpAlive tag.
2. Don't call `identify()` until the user accepts.
3. Call `setConsent({ analytics: true })` and then `identify()` in your accept handler.

```javascript
function onAccept(user) {
  HelpAlive.setConsent({ analytics: true });
  HelpAlive.identify({
    userId:   user.id,
    tenantId: user.tenantId
  });
}
```

## Logout

Logging out of your app doesn't tell HelpAlive by itself. Call `reset()` in your logout code, as [Identify](/sdk/identify#logging-out) shows, so the browser forgets the person. To also withdraw consent on logout (useful on shared devices), call `setConsent` there too:

```javascript
function logout() {
  HelpAlive.reset();
  HelpAlive.setConsent({ analytics: false });
  // …your logout logic
}
```

## What's stored when the user says no

Nothing. With `analytics: false`:

- No activity is recorded.
- No session is created.
- No device fingerprint, IP, or browser data is collected.
